# Рассылки (Broadcast flow)

## Флоу админа

```
/broadcast
→ Название (до 100 симв.)
→ Текст (MarkdownV2, до ~80К; режется на части по 4096)
→ Фильтры получателей (кнопки, всё опционально):
    план (все/paid/free) · статус (active по умолчанию/all/revoked)
    дата регистрации (3/6/12 мес) · неактивность (0/30/90 дней)
    платили когда-либо (да/нет)
→ Превью + счётчик получателей → «Отправить сейчас» или «Запланировать»
→ Планирование: день (сегодня/завтра/+3д/+6д) → час (МСК) → подтверждение
```

Отмена в любой момент: `/cancel` или кнопка «❌ Отмена».

## Доставка (фоновый воркер)

- Кампания сохраняется в БД; получатели снапшотятся в `recipients_state` —
  дубли невозможны, рестарт безопасен (claim-транзакция, восстановление
  просроченных аренд).
- Воркер опрашивает каждые 15 сек; батчи по 100, параллельность 10, таймаут кампании 5 мин.
- На сообщение: до 3 попыток (linear backoff); флуд 429 ждёт `retry_after` (до 5 раз).
- Итоги: `sent` / `blocked` (заблокировали бота) / `unreachable` / `failed`; отчёт — админу.
- Инфраструктурные сбои: retry кампании с exponential backoff (5 сек → 15 мин),
  статусы `scheduled → running → completed / failed / canceled`.

## Управление

- `/broadcasts` — история: детали кампании, отмена активной, повтор failed-получателей.

## Код

- `internal/bot/broadcast_flow.go` — session state machine админского флоу
- `internal/bot/broadcast_worker.go` — доставка кампаний
- `internal/bot/broadcast_filters.go`, `broadcast_callbacks.go`, `broadcast_report.go`
- `internal/database/broadcasts*.go` — хранение (фильтры — JSON в `broadcasts.filters`)
