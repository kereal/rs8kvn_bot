# 6–12 июля 2026

**Неделя большой полировки: подписки совместимы с большим числом клиентов, а рассылки стали безопаснее**

За неделю в Git зафиксировано 56 рабочих коммитов — это самый высокий темп за весь подготовленный период. В результате rs8kvn_bot получил одновременно усиление subserver, новый Xray-конвертер и полностью переработанный сценарий админской рассылки.

**Ключевые обновления:**

• **Share-ссылки стали заметно совместимее.** Конвертеры корректнее обрабатывают VMess, VLESS, Trojan, Shadowsocks, Hysteria2 и TUIC: ALPN, TLS/security, IPv6, HTTP-obfs, xhttp/splithttp, SIP002 plugin и параметры клиентов нормализуются под целевой формат.

• **Добавлена генерация Xray outbound JSON.** Подписочный сервер может формировать валидную конфигурацию для Xray из входных данных Clash/JSON. Отдельно исправлены несовместимости вроде `h2 → http`, `raw → tcp` и неподдерживаемого TUIC в Xray-пути.

• **Источник больше не ломает всю подписку.** Fetch upstream выполняется с ограниченным параллелизмом, не-2xx ответы отбрасываются, а access log получает статистику вида «успешно источников / всего попыток». Оператор видит не только HTTP-статус, но и качество агрегации.

• **Рассылка получила draft → preview → confirm.** Администратор сначала готовит текст, получает предпросмотр и только потом запускает отправку. Длинные сообщения делятся на чанки, MarkdownV2 форматирование сохраняется, а ошибки заблокированных пользователей отделяются от реальных сбоев.

• **MarkdownV2 больше не требует ручной рутины.** Обычный текст экранируется автоматически, при этом `bold`, italic, code и ссылки остаются форматированными. Некорректный текст можно обнаружить на этапе preview, до массовой отправки.

• **Повторные попытки синхронизации стали точнее.** Исправлен порядок расчёта retry-времени, улучшена обработка ответов панели и устранены сценарии бесконечных повторов при дубликате клиента.

**Самое заметное достижение недели** — совместимость перестала быть обещанием «в целом». Она закреплена отдельными нормализаторами и тестами для конкретных форматов, транспортов и клиентских параметров.

Протестируйте подписку в своём клиенте, особенно Xray/Clash-сценарии, и попробуйте новый flow рассылки. Реакция и реальные конфигурации — лучший способ найти следующий край совместимости.
